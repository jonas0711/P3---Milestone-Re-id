\chapter{Problem Statement} \label{cha: problemstatement}

Based on the findings in the problem analysis in Chapter \ref{cha:problemanalysis}, it is evident that a person re-identification system can be a valuable tool for society, if designed correctly: Ethical considerations are essential to ensure that the right to privacy is respected, and that the system remains trustworthy for real-world deployment. For this reason the system should be cloud deployed, to ensure controlled usage, and manage access to the system. 
The technical analysis in Chapter \ref{cha: technicalanalysis}, provides an insight into the limitations caused by hardware and environment, as well as the challenges in the task of person re-identification. The related works out-of-distribution test highlights the potential for further work on the subject. Based on these findings, the problem statement is formulated as follows:
\\\\
\textit{"How can a person Re-identification system be designed and deployed as a proof-of-concept, to improve performance through combination with super-resolution?"}
