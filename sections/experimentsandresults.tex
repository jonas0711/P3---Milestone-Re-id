\chapter{Experiments and Results} \label{cha: experiments and results}
 This chapter presents the experiments conducted to evaluate \hyperlink{hypothesis:1}{\textit{Hypothesis 1}} and \hyperlink{hypothesis:2}{\textit{Hypothesis 2}} as defined in Section \ref{sec:hypotheses}. The objective is to determine whether incorporating an \acs{SR} module improves the robustness of a person \acs{ReID} module with the \acs{InD} and \acs{OOD} conditions in mind. To support this evaluation, this chapter first presents an independent assessment of the chosen \acs{SR} model, followed by the four models defined in Section \ref{sec:model_definitions}: the \hyperlink{model:baseline}{Baseline} model, the \hyperlink{model:augmented}{Augmented} model, the \hyperlink{model:sequential}{Sequential} model, and the \hyperlink{model:endtoend}{End-to-end} model. The results from these experiments are presented and briefly discussed. 

\section{SR Experiments} \label{sec: srexperiments}
Before integrating \acs{SR} into the \acs{ReID} pipeline, the selected \acs{SR} architecture is evaluated independently, as to verify that it provides meaningful improvements over simple interpolation methods. This section presents the evaluation results and a direct comparison between \acs{EDSR} and bicubic interpolation.

\subsubsection{EDSR vs. Bicubic Interpolation}
To verify that \acs{EDSR} provides meaningful improvements over simple interpolation methods, as described in \hyperlink{req:1}{\textit{Requirement 1}}, a direct comparison was conducted between the trained \acs{EDSR} models and bicubic interpolation.
\\\\
Both \acs{EDSR} models and bicubic interpolation were evaluated on the same \acs{RELLISUR} test set. Table \ref{tab:edsr_vs_bicubic} presents the comparison results. The scratch \acs{EDSR} model achieved a mean \acs{PSNR} of 28.25 dB compared to 27.15 dB for bicubic interpolation, representing an improvement of 1.10 dB. The finetuned \acs{EDSR} model achieved 28.09 dB, representing an improvement of 0.94 dB over bicubic interpolation. For \acs{SSIM}, the scratch model achieved 0.9751 compared to 0.9689 for bicubic (improvement of 0.0061), and the fine-tuned model achieved 0.9733 (improvement of 0.0044). These results indicate that \acs{EDSR} consistently outperforms bicubic interpolation across all evaluated metrics.

\section{Out-of-Distribution Test} \label{sec: oodtestny}
Since the implemented person \acs{ReID} model was trained on the Market-1501 dataset, a new \acs{OOD} test had to be designed to fulfill this project's definition of an \acs{OOD} test, as described in Section \ref{outofdistributiontest}. This \acs{OOD} test was conducted using the test set from \acs{DukeMTMC} under three different conditions, as well as the entire \acs{iLIDS-VID} dataset, which is unseen by \acs{OSNet}. An overview is presented in Table \ref{tab:newood_conditions}.
\\\\
The test on \acs{DukeMTMC} uses 2,228 query images and 17,661 gallery images, while \acs{iLIDS-VID} uses the 300 images from camera 1 as query and the other 300 images from camera 2 as the gallery. This larger test set directly improves the representativeness of the evaluation. Since \acs{iLIDS-VID} contains only two images per identity, the evaluation remains a one-shot setting. In contrast, \acs{DukeMTMC} includes multiple gallery images per identity, making it a multi-shot evaluation. Therefore, \acs{DukeMTMC} was evaluated using Rank-\textit{k} accuracy and \acs{mAP}, while \acs{iLIDS-VID} was evaluated using only Rank-\textit{k} accuracy.

\section{Experiments} \label{sec: experimentsdefined}

In order to determine whether implementing an \acs{SR} module in the \acs{ReID} pipeline improves performance, several experiments were conducted to establish a clear and fair comparison. The experiments are designed to test the hypotheses defined in Section \ref{sec:hypotheses}. 
\\\\
Before incorporating the \acs{SR} module, the effects of applying strong data augmentation during training is first evaluated, to determine whether robustness to \acs{OOD} conditions can be achieved through training strategies alone. This step provides a reference point to determine whether the additional complexity introduced by the \acs{SR} module is justified. 

\subsection{Experiment One: Augmented Model} \label{sec: baselineosnet}

This experiment was conducted to evaluate \hyperlink{Hypothesis 1}{\textit{Hypothesis 1}}, which states that training a person \acs{ReID} module on augmented data will improve robustness under \acs{OOD} conditions.  
\\\\
Two models were compared: the \hyperlink{Baseline}{Baseline} model and the \hyperlink{Augmented}{Augmented} model. Both models share the same architecture, training datasets, and training procedure, ensuring that the applied augmentation strategy is the only variable that can affect performance. Evaluations were conducted using the \acs{OOD} test as described in Section \ref{sec: oodtestny}. 
\\\\
This experiment establishes whether robustness to \acs{OOD} conditions can be achieved through training strategies alone, without introducing additional components to the \acs{ReID} module. 
 

\subsection{Experiment Two: \acs{EDSR} and Baseline Combined} \label{sec: sr+baseline}

This experiment was conducted to evaluate \hyperlink{Hypothesis 2}{\textit{Hypothesis 2}}, by investigating if adding \acs{EDSR} as a preprocessing step improves \acs{ReID} performance under \acs{OOD} conditions. 
\\\\
Two model configurations were compared: the \hyperlink{Baseline}{Baseline} model and a sequentially combined \acs{EDSR} and \hyperlink{Baseline}{Baseline} model, where images are first preprocessed by the \acs{SR} module and subsequently passed to the \acs{ReID} module. The \acs{ReID} model architecture, training data, and training strategies remained identical to the ones used in the \hyperlink{Baseline}{Baseline} model configuration.
\\\\
In this setup, with the \acs{EDSR} and \hyperlink{Baseline}{Baseline} modules combined without joint end-to-end training, the effect of \acs{SR} as a preprocessing step on \acs{ReID} performance can be evaluated independently. 


\subsection{Experiment Three: End-to-end \acs{EDSR} and Baseline}

This experiment was conducted to further evaluate \hyperlink{Hypothesis 2}{Hypothesis 2} by assessing if joint end-to-end training of the \acs{SR} and \acs{ReID} module improves robustness under \acs{OOD} conditions.
\\\\
The \hyperlink{End-to-end}{End-to-end} model is compared against the \hyperlink{Sequential}{Sequential} model. Both configurations used the same \acs{EDSR} and \hyperlink{Baseline}{Baseline} model, with the only difference being the training strategy of the configurations. Where the \hyperlink{Sequential}{Sequential} model was combined, the \hyperlink{model:endtoend}{End-to-end} model trained the \acs{EDSR} and \hyperlink{model:baseline}{Baseline} models jointly, allowing the \acs{SR} module to adapt specifically to the \acs{ReID} task.
\\\\
By keeping the other factors constant, this experiment isolated the effect of joint end-to-end training compared to sequential integration.
