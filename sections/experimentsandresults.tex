\chapter{Experiments and Results} \label{cha: experiments and results}
 This chapter presents the experiments conducted to evaluate \hyperlink{hypothesis:1}{\textit{Hypothesis 1}} and \hyperlink{hypothesis:2}{\textit{Hypothesis 2}} defined in Section \ref{sec:hypotheses}. The objective is to determine whether incorporating an \acs{SR} module improves the robustness of a person \acs{ReID} module under \acs{OOD} conditions. To support this evaluation, this chapter first presents an independent assessment of the chosen \acs{SR} model, followed by four experimental configurations: The \hyperlink{Baseline}{Baseline} model, the \hyperlink{Augmented}{Augmented} model, the \hyperlink{Sequential}{Sequential} model, and the \hyperlink{End-to-end}{End-to-end} model. The results from these experiments are presented and briefly discussed. 

\subsection{SR Experiments} \label{sec: srexperiments}

Before integrating \acs{SR} into the \acs{ReID} pipeline, the selected \acs{SR} architecture is evaluated independently to verify that it provides meaningful improvements over simple interpolation methods. A direct comparison between \acs{EDSR} and bicubic interpolation was conducted to provide a natural baseline for comparison with deep learning-based \acs{SR} methods.
\\\\
Bicubic interpolation is a traditional image upscaling method that uses a cubic polynomial to estimate pixel values, providing a natural baseline for comparison with deep learning-based \acs{SR} methods.
\\\\
The evaluation compares the trained \acs{EDSR} model against bicubic interpolation using the same test conditions. Both methods are applied to low-resolution images from the test set, and the upscaled outputs are evaluated using \acs{PSNR} and \acs{SSIM} metrics. The results demonstrate that \acs{EDSR} consistently outperforms bicubic interpolation across all evaluated metrics. On the test dataset, \acs{EDSR} achieves a mean \acs{PSNR} of [PLACEHOLDER] dB compared to [PLACEHOLDER] dB for bicubic interpolation, representing an improvement of [PLACEHOLDER] dB. Similarly, \acs{EDSR} achieves a mean \acs{SSIM} of [PLACEHOLDER] compared to [PLACEHOLDER] for bicubic interpolation. These results show that \acs{EDSR} performs better than bicubic interpolation.



\section{Out-of-Distribution Test} \label{sec: oodtestny}
Since the implemented person \acs{ReID} model was trained on the Market-1501 dataset, a new \acs{OOD} test had to be designed to fulfill this project's definition of an \acs{OOD} test, as described in Section \ref{outofdistributiontest}. This \acs{OOD} test was conducted using the test set from \acs{DukeMTMC} under three different conditions, as well as the entire \acs{iLIDS-VID} dataset which is unknown to \acs{OSNet}. They are presented in Table \ref{tab:newood_conditions}.
\\\\
The test on \acs{DukeMTMC} has 2,228 query and 17,661 gallery images, while \acs{iLIDS-VID} uses the 300 images from camera 1 for query and the other 300 images from camera 2 for gallery. This increase in data increases the representativeness of this evaluation. Since \acs{iLIDS-VID} contains only two images per identity, the evaluation remains a one-shot setting. In contrast, \acs{DukeMTMC} includes multiple gallery images per identity, making it a multi-shot evaluation. Therefore, \acs{DukeMTMC} was evaluated using Rank-\textit{k} accuracy and \acs{mAP}, while \acs{iLIDS-VID} is evaluated using Rank-\textit{k} accuracy only.

\section{Experiments}

The \acs{OOD} test conducted in Section \ref{sec: oodtestny} highlights that the off-the-shelf \acs{OSNet} model fails when confronted with images that are heavily augmented and simulate the domain shift encountered in real-world deployment. In order to determine whether implementing an \acs{SR} module in the \acs{ReID} pipeline, several experiments were conducted to establish a clear and fair method for comparison. The experiments are designed to test the hypotheses defined in Section \ref{sec:hypotheses}. 
\\\\
Before incorporating the \acs{SR} module, the effect of applying strong data augmentation during training is evaluated first, to determine whether robustness to \acs{OOD} conditions can be achieved through training strategies alone. This step provides a reference point to determine whether the additional complexity introduced by the \acs{SR} module is justified. 

\subsection{Experiment One: Augmented Model} \label{sec: baselineosnet}

This experiment was conducted to evaluate \hyperlink{Hypothesis 1}{Hypothesis 1}, which states that training a person \acs{ReID} module on augmented data will improve robustness under \acs{OOD} conditions.  
\\\\
Two models were compared: the \hyperlink{Baseline}{Baseline} model and the \hyperlink{Augmented}{Augmented} model. Both models share the same architecture, training datasets, and training procedure, ensuring that the applied augmentation strategy is the only variable that can affect performance. Evaluations were conducted using the \acs{OOD} test as described in Section \ref{sec: oodtestny}. 
\\\\
This experiment establishes whether robustness to \acs{OOD} conditions can be achieved through training strategies alone, without introducing additional components to the \acs{ReID} module. 
 

\subsection{Experiment Two: \acs{EDSR} and Baseline Combined} \label{sec: sr+baseline}

This experiment was conducted to evaluate \hyperlink{Hypothesis 2}{Hypothesis 2}, by investigating if adding \acs{EDSR} as a preprocessing step improves \acs{ReID} performance under \acs{OOD} conditions. 
\\\\
Two model configurations were compared: the \hyperlink{Baseline}{Baseline} model and a sequentially combined \acs{EDSR} and \hyperlink{Baseline}{Baseline} model, where images are first preprocessed by the \acs{SR} module and subsequently passed to the \acs{ReID} module. The \acs{ReID} model architecture, training data, and training strategies remained identical to the ones used in the \hyperlink{Baseline}{Baseline} model configuration.
\\\\
In this setup, with the \acs{EDSR} and \hyperlink{Baseline}{Baseline} modules combined without joint end-to-end training, the effect of \acs{SR} as a preprocessing step on \acs{ReID} performance can be evaluated independently.

\subsection*{Out-of-Distribution Scale Test}
Inspecting the result of the \acs{OOD} scale test, all metrics increase with the scale reduction of 0.75 compared to the unmodified images. 
\\\\
This is assumed to be caused by the presence of differently sized images in the new dataset compared to those used during training. Since the model is trained with a maximum image size of \textit{128×64}, it is not fully equipped to handle the larger or differently scaled images. As expected performance drop again across all metrics, when testing on scale 0.5.

\subsection*{Out-of-Distribution Test on iLIDS-VID}

The results for the test on the \acs{iLIDS-VID} dataset is better than those on DukeMTMC-ReID, except for Rank-5. These results can although not be compared fairly one to one, because of the difference in test setups, where DukeMTMC-ReID has a big test set and is multi-shot evaluation while \acs{iLIDS-VID} is much smaller and one-shot learning, making the tests very different. 
\\\\
The results for \acs{iLIDS-VID} is although far from the validations results, showing that the model has difficulty generalizing to this new and different dataset. As mentioned in Section \ref{outofdistributiontest} \acs{iLIDS-VID} is different than the datasets used for training, this contribute to this decrease in performance.
