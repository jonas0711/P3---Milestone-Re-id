\chapter{Requirement Specification} 
\label{cha:reqspec}

As defined in the problem statement, this project focuses on building and testing how \acs{SR} can be combined with and improve the performance of \acs{ReID}. Consequently, the requirements will focus on these two networks and their integration. For that same reason, the requirements will not describe a complete \acs{ReID} system and are therefore not exhaustive. The scope implies that the \acs{SR} and \acs{ReID} integration does not include an object detection module, and thus expects cropped images as input.
\\\\
Each requirement will be testable and measurable with defined success criteria, and have a traceability tag.
